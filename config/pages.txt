# The Official Guides the kit saves for reading without internet (and, in Ukrainian, for the AI to read).
# Saved by scripts/fetch-pages.py, checked every week by scripts/check-links.py. Not redistributed from this repo.
#
# One guide per line:  language | address | file name (the source's name, " - ", the title; no extension)
#   - The language is the language of the page. Guides in the country's own language (uk) are marked for the AI
#     index; guides in other languages are saved for reading only, in a subfolder named by the language code.
#   - The file name is what the guide is called on the start page and in the reader, and what the Emergency Topics in
#     config/country.json refer to. It starts with the source's id (official_guides.sources in that file).
#   - An address ending in .pdf is saved as the PDF itself, anything else as text.
#   - Sources marked optional in the country config (the State Emergency Service) are skipped quietly when they refuse.
# Addresses were checked 2026-11-19 from outside Ukraine, except the State Emergency Service ones, which refuse requests from there.
